## Required permissions and data flow

This skill includes four standard-library Python helpers, not a background service. Extraction/installation does not run them. The main agent must have permission to run Python and to read the specific project/research evidence approved for the task. Audit files, provider configuration and any credential storage are written only when their commands are invoked. Keep private configuration and credentials outside the installed skill folder.

**Credential access:** `api_key_env` in your selected provider profile names the one credential variable to read (for example `DECISION_API_KEY` or a provider's documented variable). Only that configured credential is used; the helper does not enumerate environment variables or collect other providers' keys. Optional `DECISION_GATE_CONFIG`/`JEV_GATE_CONFIG` select a config file, and user-supplied private paths may expand environment/home settings. Windows DPAPI credential storage is an optional, explicitly configured alternative. No credential, account session or API credit is included.

**Network:** eligible screening requests send the supplied task and approved evidence to the HTTPS endpoint in the selected profile; the selected provider's key is used for authentication. The example default is `https://api.typesafe.ai/v1/systemone`. Optional profiles show GapGPT, OpenRouter, Anthropic-compatible Messages and a local Ollama-compatible endpoint. Choose only a provider you trust and use its own credential. There are no analytics, telemetry or automatic GitHub/Skills.sh requests in the runtime helpers. Documentation links are informational. Small inputs bypass the provider; unavailable/rejected routing retains original evidence under the bounded retry policy. Provider charges may apply separately.

**Boundaries:** remote endpoints require HTTPS/authentication, TLS validation remains enabled, redirects are refused, and unauthenticated HTTP is restricted to explicitly permitted literal loopback addresses. Never send secrets, unrelated private data or the whole chat history as evidence. The helper cannot redact arbitrary secrets for you. Configuration paths shown in the setup documents are ordinary user-owned settings paths, not destructive commands. No shell-evaluation, remote-script installation, dependency download, MCP server or lifecycle hook is bundled.

The Agensi ZIP intentionally omits development tests, benchmark runners, installer tooling and binary media. The installation video, full test sources and audit methodology remain on the public GitHub repository. Read [setup](https://github.com/MehradYaghoubi/jev-research-engineering/blob/main/references/setup.md) and [access methods](https://github.com/MehradYaghoubi/jev-research-engineering/blob/main/references/access.md) before configuring a paid endpoint.
